# Scenes — establishing art for Bad Blood

*Midjourney prompts for **setup / splash images** — the moments worth showing players on a screen. Same workflow as the portraits and maps: generate, save with the exact `Image file` name, and drop it into the arc folder (or a `Scenes/` subfolder) — then it embeds. Every prompt is `--ar 16:9` for a wide splash. Append a shared `--sref` / `--style raw` to keep the set consistent, and `--no people, characters, text` on the pure-environment ones if faces keep appearing.*

> [!tip] Where to show them
> Reveal a scene image **as you read its boxed text** — the campfire as you open, the tavern as they arrive, the green-candle crypt as the trap springs. Drop the audio/ambience at the same beat (see [[Ambience & Soundtrack]]).
