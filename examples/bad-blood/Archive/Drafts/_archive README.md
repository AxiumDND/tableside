# _archive — what's in here and why

*Nothing in this folder is current. It is kept because the vault's convention is that old drafts go to `_archive/`, never to the bin. **Don't edit anything here, and don't run from it.** For the arc as it actually happened, see [[Session 3 — Actual Play]] and [[Bad Blood — Arc Conclusion & Continuity]].*

## Superseded session drafts
Rewrites of the run guides, kept so the evolution of the arc is traceable. Each is named with the date it was superseded and what changed after it.

- `Session 2 — superseded 15 July 2026 (pre-S1-actual version)` — written before Session 1 was played; the S1 outcomes made it wrong.
- `Session 2 — superseded 19 July 2026 (pre-crypt-map version)` — before the crypt was mapped room-by-room.
- `Session 3 — superseded 21 July 2026 (coach-ending version)` — **the version with the coach, the Farewell letter and Ernst Larnak.** Cut on 21 July… and then partly reinstated at the table on the night. **If you ever want the ending as originally written, it's this file.**
- `Session 3 — superseded 25 July 2026 (pre-table-map version)` — before `Map session 3.jpeg` was built.
- `Session 3 — superseded 25 July 2026 (pre-vestige version)` — before the Choir Below / Binding / Unchaining rewrite.

## Retired planning docs *(archived 14 August 2026, arc complete)*
- `Arc Plan — Four Sessions` — the arc's planning changelog. Useful as a record of how the shape changed between sessions; useless as prep now.
- `Revised Session Flow — Post Session 0.5` — a mid-arc re-plan, long since overtaken.
- `Session Recaps & Aftermath` — pre-written "previously on…" recaps and reaction notes, written before the sessions happened. **Superseded by what actually happened** — use the three `— Actual Play` and `— WhatsApp Recap` files instead. *(Worth skimming once if you want the planned-vs-played contrast.)*

## Still live, deliberately not archived
These look finished but are **unspent prep you can reuse** — they stay in `Reference/`:

- `Tavern — Blood o' the Vine (Backup)` — a whole mini-adventure, never played, maps already printed.
- `Ravenkind Shard` — the handover that never happened.
- `Going Off-Script & Failure States`, `Dread & Omens`, `Setting Rules — Barovia`, `The Mists — Getting In & Out` — system-level, not arc-specific. Reusable in any Ravenloft game.
