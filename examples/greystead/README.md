# Greystead — The Pale Well

Level 1 one-shot. Tableside copies this folder into your user data when you first launch or click **Sample**, so edits stay out of the install bundle.

## Run it

1. Open **Start Here → Overview**, then **Sessions → Session 1 — Game Night Sheet**. That note is the night; **Session 1** holds prose and reference.
2. Pregens are in **Party/** (up to 6). Town and the cave are in **Places/** and **Maps/**.
3. **Add to initiative** on the combat headings. Click art, then **Show to players**.
4. Handouts are in **Handouts/** — letter, orders, crate scrap, hymn. Show the pictures when they find them.
