# Security Policy

## Supported versions

Security fixes land on the latest Tableside release on
[GitHub Releases](https://github.com/AxiumDND/tableside/releases/latest).
Older installers are not backported.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Email **[tableside.gm@gmail.com](mailto:tableside.gm@gmail.com)** with:

- What you found and how to reproduce it
- Tableside version (Help & settings, or the installer filename)
- OS version

You should get a reply within a few days. If the report is valid, a fix will
ship in a normal release when ready.

## Scope

In scope: the Tableside app, installer, auto-update check against GitHub
Releases, and this repository’s CI/release workflows.

Out of scope: Windows SmartScreen warnings on the **unsigned** hobby installer
(expected — see the README), third-party campaign content, and optional local
book dumps in `Additional Books/`.
