# WOTC lookup files

Drop your own book text here. Table DM does not ship Player’s Handbook or other Wizards books.

When this folder has files Lookup can read, extra filter chips appear and search includes that text.

## Supported now

- `*Spell*` `.md` / `.txt` — one spell per `##` heading, then school/level, Casting Time, Range, Components, Duration, and the body
- `*Equipment*` `.md` / `.txt` — one weapon, armor, tool, gear item, or rule per `##` heading
- `*Magic Item*` `.md` / `.txt` — one magic item per `##` heading, then type, rarity, and attunement

The installed app also looks in `%APPDATA%\table-dm\WOTC`.
