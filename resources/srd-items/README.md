# SRD gear and magic item art

Default D&D-fantasy still-life images for SRD weapons, armor, adventuring gear, tools, and magic items. Campaign files in `Gear/.../Art/` win if present.

Name each file exactly after the SRD item (`Longsword.webp`, `Potion of Healing.webp`).

These are original generated illustrations, not official Wizards of the Coast art.

To convert new PNGs: `npm install --no-save sharp` then `node scripts/convert-srd-items.mjs`.
