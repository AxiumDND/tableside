# Bundled dice roll sounds

Recordings played on **Roll** (tray, statblocks, Box of Doom) and on the Music soundboard chips **Dice (one)** / **Dice (two)** / **Dice (handful)**. If a file is missing, that clip falls back to the synthesized clatter.

## Files

| File | When it plays |
| --- | --- |
| `dice-one.wav` | One die (`1d20`, `1d6`, …) |
| `dice-two.wav` | Exactly two dice (advantage, `2d6`, Box of Doom pair) |
| `dice-handful.wav` | Three or more (`2d6+1d8`, a handful) |

Same stems, other formats also work: `.mp3` `.ogg` `.m4a` `.flac` `.webm` `.aac`. Keep clips dry — the mixer already has an Sfx fader.

These ship in the installer via `extraResources` (`dice-sfx/`). Do not put them in a campaign `Audio/` folder.
